## 🛠️ Troubleshooting

### Common Issues and Solutions

**Issue: Application won't start**
- Make sure you have the latest Windows updates installed
- Try running the application as administrator (right-click and select "Run as administrator")
- Check if your antivirus is blocking the application

**Issue: Can't connect to AI services**
- Verify your internet connection is stable
- Check if you're logged into your Nexscope account
- Try restarting the application

**Issue: Videos not generating**
- Ensure you're using supported image formats (JPG, PNG, or WEBP)
- Check that your images meet the minimum resolution requirements
- Try reducing the video length
